# 最终边接收密度敏感性报告

## 结论先行

三档均完成双算法疏散，所有运行均为 17,905 人、人数守恒误差 0、循环/反向/断裂 0、Gate 重复服务与容量违规 0。

结果不支持把 3.0 或 3.9 称为“现实最优值”。Improved 三档完全不变，是因为边接收硬上限从未触发；AA 在 3.0 与 3.9 几乎相同，而默认值仅在部分阻挡、排队和路径分配上略有差别。敏感性结果只能说明模型内响应，不能替代现场标定。

## 严格解释

- 默认值是当前正式默认参数，不代表已经完成现实标定。
- 3.0 与 3.9 是敏感性情景，不是推荐值。
- Improved 对参数完全不敏感暴露出该参数在其运行轨迹上没有约束力，而不是证明算法稳健或参数正确。
- AA 三档 T100 相同，但内部阻挡类型、Gate 排队和密度暴露发生变化；只比较 T100 会遗漏风险转移。
