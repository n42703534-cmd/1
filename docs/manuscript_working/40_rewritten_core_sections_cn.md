# 面向多线换乘站共享瓶颈协调的到达时刻队列感知疏散路径规划

## 摘要（高负荷结果版）

多线换乘站的疏散路径不仅决定乘客移动距离，也决定不同客流批次到达共享楼扶梯、通道和出口的先后次序。若路径代价只读取决策时刻的设施状态，尚未到达但已经被分配至同一瓶颈的客流不会进入当前判断，可能导致未来服务需求被持续低估。针对这一状态—到达错位，本文提出到达时刻队列感知 A*（arrival-time queue-aware A*，AA*）。该方法把容量受限设施表示为共享服务资源，按已承诺客流的到达事件推进队列，并在时变多标签搜索中逐段累计移动时间、预计资源等待、空间接纳等待和密度暴露代价。研究以龙阳路多线换乘站为案例，站体几何来自项目 CAD；设置 2,187 人基准需求和在其上叠加两列各线路列车客流的 17,905 人高负荷需求。AA* 与 Improved A* 共用相同的物理加载层，并通过逐模块消融识别性能来源；两组路径进一步映射到 Pathfinder 连续空间模型，同时设置 Pathfinder Goto Any Exit 作为软件原生自主选出口参照。高负荷网络仿真中，AA* 相比 Improved A* 将 $T_{95}$ 从 1125 s 降至 889 s、$T_{100}$ 从 1486 s 降至 1222 s，累计静止暴露降低 32.4%，但总移动距离增加 15.5%，计算时间增至 16.3 倍。消融显示，资源队列等待代价是识别服务瓶颈的基础，到达时刻预测提供主要增益；密度暴露和多标签搜索主要影响最末端清空。Pathfinder 高负荷复现中，AA* 路径的平均完成时间和 $T_{100}$ 分别比 Improved A* 路径降低 9.1% 和 8.2%。Pathfinder Goto Any Exit 的平均完成时间最短，但 $T_{100}$ 最长，表明典型乘客效率与残余尾部清空并非同一目标。研究由此把复杂换乘站疏散路径规划表述为共享服务能力上的到达时刻协调问题，并给出尾部收益、等待暴露、绕行与计算代价的联合证据。

关键词：地铁站疏散；动态路径规划；到达时刻队列；共享瓶颈；Pathfinder；多线换乘站

## 1 引言

多线换乘站在有限空间内连接多个站台、站厅、换乘通道和地面出口。全站疏散时，站台候车客流、列车到达客流、站厅客流和换乘客流并非沿相互独立的通道离开，而是在不同位置和时刻竞争同一组楼梯、自动扶梯、闸机区和出口。局部容量不足由此不只造成设施附近的瞬时拥堵，还会沿客流链向上游传播，并延迟与该瓶颈相距较远的客流批次。把站内空间表示为由活动区域、竖向设施和出口组成的有向设施网络，可以描述这种跨线路耦合；若进一步把设施服务过程与路径选择联立，则可以分析路径分配如何改变拥堵形成和消散。

既有地铁站疏散研究已经从不同角度连接空间建模、路径优化和微观仿真。设施网络研究通过节点过载和流量重分配描述相互依赖的站内设施；动态客流研究把路径选择、节点排队和流量加载结合；面向实际地铁站的仿真—优化研究通常依次给出站体建模、场景构造、优化过程、疏散快照或密度分布，再以完成时间、拥堵和出口流量评价方案。Yang 等在洪水疏散研究中进一步将水动力、结伴行为、道路中断和路径优化连接到 Pathfinder 执行评价。上述工作共同说明，疏散路径不能只以几何长度衡量，结果也不能只由一个全站完成时间支撑。

对于多个批次共享容量设施的情形，仍存在一个直接影响路径选择的时间错位。乘客在时刻 $t_0$ 做出决策，但其真正进入楼梯、闸机区或出口的时刻为未来的 $\tau$。在 $t_0$ 与 $\tau$ 之间，设施会继续服务当前队列，也会接收其他已经分配但尚未到达的客流。如果候选路径仍以 $t_0$ 的可见密度或队列计算代价，就会忽略这些已承诺的未来到达量，使当前看似通畅的设施在乘客抵达前转化为瓶颈。因此，本文关注的不是再次调整几何最短路权重，而是把共享设施状态推进到候选客流的预计到达时刻。

基于此，本文提出到达时刻队列感知 A*（AA*），并围绕一个主问题展开：在无火灾、建模设施均可用的多线换乘站疏散中，把当前队列、在途承诺流量和设施服务过程推进至预计到达时刻，能否减少共享瓶颈的等待暴露并压缩 $T_{95}$–$T_{100}$ 尾部？为回答该问题，研究进一步考察三个方面：其一，AA* 相比 Improved A* 是否改变站级完成分布和线路清空过程；其二，变化如何通过关键设施及来源—出口流量重分配形成，并对应多少额外移动与计算代价；其三，资源等待、到达时刻预测、空间接纳、多标签与密度暴露机制分别贡献什么，以及网络模型中的差异能否在 Pathfinder 连续空间运动中复现。

本文的贡献体现在三个层次。第一，在路径代价中显式区分决策时刻和预计到达时刻，把共享资源当前队列、服务消化和已承诺到达事件纳入同一队列推进过程。第二，在共同物理执行层下，通过完整 AA*、Improved A* 和五个单模块变体建立“总体结果—设施机制—模块贡献”的证据链。第三，将网络模型输出的两组路径映射到同一 Pathfinder 站体模型，并以 Pathfinder Goto Any Exit 补充自主选出口参照，从平均完成、上尾清空、拥堵暴露和移动距离四个维度检验不同运行点。

## 3 方法中的 Pathfinder 定位

### 3.X 跨模型微观复现协议

网络模型负责生成客流批次的路径和出口分配，Pathfinder 负责在连续空间中执行这些分配。本文不把 Pathfinder 作为优化算法的真值，而是用它检验网络路径在另一套运动表征、碰撞规避和局部拥堵机制下是否保持相同的结果方向。

高负荷复现包含三个协议。第一，Improved A* 协议把网络模型输出的 Improved A* 完整路径合并为 Pathfinder 行为分配；第二，AA* 协议以相同方式映射 AA* 路径；第三，Pathfinder Goto Any Exit 协议使用模型文件中的 `goto exit any` 行为，由软件自主选择可达出口。Pathfinder 技术手册把其内部路径规划机制表述为 Locally Quickest；本文使用该术语解释软件机制，但不另造“PF-LQ”算法名称。

三组协议均使用相同的站体几何和 17,905 人总需求；三个 `.geom` 文件的 SHA-256 完全一致。Improved A* 与 AA* 的乘客姓名集合一致，可按姓名计算完成时间差；参数审计同时记录了少量 ID、房间、初始位置和朝向差异，因此配对结果作为描述性乘客级比较报告。Goto Any Exit 场景与预分配路径场景在大量个体参数和初始位置上不同，故仅比较场景级经验分布，不进行同名配对。

每组 Pathfinder 输出均使用全部乘客记录。对完成时间 $T_i$ 构造经验累计分布

$$
\widehat{F}(t)=\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}(T_i\leq t),
$$

并报告平均值及 $T_{50}$、$T_{80}$、$T_{95}$、$T_{99}$ 和 $T_{100}$。拥堵暴露分为水平区域拥堵和楼梯拥堵，移动代价由乘客移动距离表示。AA* 与 Improved A* 的乘客级差定义为

$$
\Delta T_i=T_i^{\mathrm{Improved}}-T_i^{\mathrm{AA}},
$$

其中 $\Delta T_i>0$ 表示该乘客在 AA* 协议下更早完成。

## 4 实验设计中的消融

消融采用 leave-one-component-out 设计，以完整 AA* 为参照，每次仅关闭一个规划机制：资源队列等待代价、到达时刻队列预测、空间接纳等待、时变多标签或密度暴露代价。所有变体使用同一 17,905 人需求、站体、时间步长、资源服务率、下游接纳和溢回规则；Improved A* 是外部算法参照，不参与 AA* 内部模块贡献计算。

消融结果从两组量判断。第一组是疏散结果，包括 $T_{50}$、$T_{95}$、$T_{100}$、平均完成时间、累计静止人·秒、出口 Jain 指数和关键设施 Jain 指数。第二组是代价，包括总移动距离和墙钟运行时间。由于当前输出为每个确定性配置的一次完整运行，本文报告相对变化和机制一致性，不构造不存在的重复样本或显著性检验。

## 5 高负荷结果

### 5.1 站级完成与线路清空

Improved A* 与 AA* 均完成 17,905 人疏散并满足人口守恒。AA* 将平均完成时间从 438.9 s 降至 335.5 s，$T_{95}$ 从 1125 s 降至 889 s，$T_{99}$ 从 1309 s 降至 1097 s，$T_{100}$ 从 1486 s 降至 1222 s。两条完成时间剖面从平均值到完全清空均保持间隔，且 $T_{95}$–$T_{100}$ 的绝对差为 236–264 s，说明改善并非只出现在少数中段乘客，而是延伸至残余尾部。

线路结果进一步表明，全站改善通过线路间重新分配能力实现。AA* 将 2、7、16 和 18 号线的完全清空时间分别由 1483、1486、874 和 1309 s 降至 993、1222、344 和 418 s；磁浮则由 590 s 增至 651 s。7 号线在两种方法下均为最后清空线路。该结果不支持“每条线路同时改善”，而支持 AA* 以局部让渡换取全站尾部缩短。

### 5.2 移动—等待构成与流量重分配

AA* 的累计静止时间由 6.55 百万人·秒降至 4.43 百万人·秒，但累计移动时间由 1.34 增至 1.61 百万人·秒。对应地，总移动距离增加 15.5%，累计静止暴露减少 32.4%，平均完成时间减少 23.5%。因此，站级收益来自“允许更多移动以避免更长等待”，而不是缩短所有路径。该收益伴随显著计算代价：AA* 的墙钟时间为 615.3 s，Improved A* 为 37.7 s，前者约为后者的 16.3 倍。

来源—出口矩阵显示，路径差异集中在少数大流量重分配。18 号线客流从 Exit 17 向 Exit 12 转移 1650 人；16 号线减少分配至 Exit 10 的 428 人，并增加分配至 Exit 11 西侧的 446 人；磁浮客流在 18–21 号出口之间重新分布。2 号线则在多个本线出口间进行数百人的调整。每个来源线路总人数保持不变，因而这些差值直接表示出口路径组合的重构，而不是人口变化。

### 5.3 模块消融

完整 AA* 的消融基准为 $T_{95}=889$ s、$T_{100}=1222$ s。去除资源队列等待代价后，$T_{50}$、$T_{95}$ 和 $T_{100}$ 分别增加 73.2%、196.3% 和 182.7%，累计静止暴露增加 164.6%；关键设施 Jain 指数相对完整 AA* 下降 69.4%。这一变体产生最大退化，说明显式资源等待是方法识别容量服务瓶颈的基础。

保留资源等待但关闭到达时刻队列预测后，$T_{95}$ 增至 1060 s、$T_{100}$ 增至 1427 s，累计静止暴露增加 45.2%，同时运行时间减少约 11.7%。该变体的总移动距离更短，却需要更长等待，支持到达时刻预测通过提前绕开未来拥挤资源改善清空过程。

去除密度暴露项和将搜索改为单标签均不改变 $T_{95}$，但分别将 $T_{100}$ 增至 1254 s 和 1251 s；二者对平均完成和累计静止的影响接近零，说明独立作用集中在最末端残余客流。关闭规划层空间接纳等待后，各项汇总结果与完整 AA* 相同。这里的不变只针对额外的规划预测项；共同物理执行层中的有限接纳和溢回规则仍保持开启。

### 5.4 Pathfinder 高负荷微观复现

在 Pathfinder 连续空间运动中，AA* 路径相对 Improved A* 路径将平均完成时间从 435.5 s 降至 396.0 s，$T_{95}$ 从 1024.5 s 降至 985.1 s，$T_{100}$ 从 1414.6 s 降至 1298.3 s；平均拥堵时间由 311.3 s 降至 276.6 s。按姓名配对的 17,905 名乘客中，10,073 名（56.3%）在 AA* 协议下更快，7,825 名更慢，7 名相同；平均和中位时间差分别为 39.5 s 和 12.2 s。网络模型中 AA* 相对 Improved A* 的方向因此在微观执行层得以复现，但两平台的绝对时间不用于一一拟合。

Pathfinder Goto Any Exit 的平均完成时间为 362.5 s，低于 Improved A* 和 AA* 两组预分配路径；其平均移动距离也最短，为 114.6 m。然而，该协议的 $T_{95}=1034.1$ s、$T_{100}=1458.5$ s，均高于 AA* 路径的 985.1 s 和 1298.3 s。经验累计曲线在上尾发生交叉：Goto Any Exit 使较大比例乘客较早完成，却留下更长的最终清空阶段。三种协议由此形成不同运行点——Goto Any Exit 偏向平均效率，AA* 路径偏向尾部清空，Improved A* 则在两者之外具有更长的平均与尾部时间。

拥堵组成进一步解释了这种取舍。Goto Any Exit 的人均水平区域拥堵最低，但楼梯拥堵高于 AA*；AA* 的楼梯拥堵最低，而其移动距离分布高于 Goto Any Exit。该结果说明，全站平均完成、竖向设施暴露和完全清空不能由单一路径长度指标同时代表，Pathfinder 原生自主选择与网络预分配路径各自优化了不同阶段。

## 6 讨论要点

AA* 的主要收益不是几何缩短，而是减少未来共享服务竞争。网络主比较中，总移动距离与移动人·秒上升，而静止人·秒和完成尾部下降；到达预测消融又呈现“距离缩短、等待增加”的反向变化。两组证据相互补充，说明到达时刻队列是连接路径选择与瓶颈服务过程的关键状态。

Pathfinder Goto Any Exit 揭示了平均效率与尾部清空的分离。自主选出口能够让大量乘客快速完成，但局部选择累积后，少量乘客可能进入持续更久的残余阶段。AA* 通过批次级协调牺牲部分个体的最短路径机会，以压缩共享瓶颈的最终清空。因而本文不把方法结论写成“全面优于”，而把贡献界定为尾部与等待暴露的协调改善，并同时量化移动和计算代价。

从实施形式看，AA* 的运行代价明显高于 Improved A*，更适合转化为列车/站台/客流批次级的引导策略，而不是要求每名乘客进行高频个体重规划。低负荷结果完成后，将进一步检验共享设施竞争减弱时，资源等待、到达预测和尾部机制的效应幅度是否收敛。
